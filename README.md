# 🌿 ClearLeafCoin (CLF)

**ClearLeafCoin (CLF)** is a secure, transparent, and eco-inspired ERC-20 token built on the Ethereum blockchain. Designed with the community in mind, CLF aims to grow organically while offering real utility and transparency at every step.

---

## 📜 Contract Details

- **Token Name**: ClearLeafCoin  
- **Symbol**: CLF  
- **Decimals**: 18  
- **Total Supply**: 100,000,000 CLF  
- **Standard**: ERC-20  
- **Blockchain**: Ethereum (EVM compatible)  
- **Contract Address**: [`0x5C6a0Ec55013b839104017E44Af90baadcAe100D`](https://etherscan.io/address/0x5C6a0Ec55013b839104017E44Af90baadcAe100D)

---

## 🔐 Security & Simplicity

This contract was built using [OpenZeppelin](https://github.com/OpenZeppelin/openzeppelin-contracts) libraries — the most widely used and audited framework for Ethereum smart contracts.

### ✅ Key Features:
- ✅ Immutable Total Supply (fixed at deployment)
- ✅ No minting or burning functions post-deployment
- ✅ OpenZeppelin's `Ownable` contract for transparent ownership
- ✅ Fully readable and community-auditable source code
- ✅ Designed for community governance and real-world utility

---

## 🛡 Security Review

The CLF contract has been reviewed for the following:

- **No hidden mint/burn logic**
- **No upgradeable proxy complexity (simplicity prioritized)**
- **No external dependencies at runtime**
- **No reentrancy vulnerabilities**

🔒 *For additional security, the contract may renounce ownership or be governed by community voting as market cap goals are reached.*
